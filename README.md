# CryptoProgESA — Практическая работа №4

Проект содержит реализацию программ криптографической обработки данных на языке C++ с использованием библиотеки Crypto++:
1. hash — утилита вычисления криптографического хэша файла по алгоритму SHA-384.
2. cipher — утилита симметричного блочного шифрования и расшифрования файлов алгоритмом Camellia в режиме CBC с генерацией ключа из пароля.


--------------------------------------------------
1. ПРОГРАММА ХЭШИРОВАНИЯ (hash)
--------------------------------------------------
Программа вычисляет контрольную сумму указанного файла по алгоритму SHA-384 и выводит результат в виде шестнадцатеричной строки (HEX).

Сборка:
  cd hash
  make

Очистка скомпилированных файлов:
  make clean

Использование:
  ./hash <путь_к_файлу>

Параметры:
  <путь_к_файлу> — обязательный позиционный аргумент: путь к файлу, хэш которого требуется вычислить.

Пример работы:
  # Вычисление хэша файла:
  ./hash test.txt
  # Пример вывода:
  # a59740523e3cb897ef2b7c62b9f39446d32bf6e1e3427f2c7a31b4abff1d4719c8f0b18289436735c363cd4d7d3c0a52

  # Сверка со стандартной утилитой ОС:
  sha384sum test.txt

--------------------------------------------------
2. ПРОГРАММА ШИФРОВАНИЯ/РАСШИФРОВАНИЯ (cipher)
--------------------------------------------------
Программа реализует защиту данных симметричным блочным шифрованием:
* Алгоритм: Camellia (размер блока 128 бит / 16 байт, ключ 256 бит / 32 байта).
* Режим: CBC (Cipher Block Chaining).
* Ключ: формируется из введённого пароля путём хэширования через SHA-256.
* Вектор инициализации (IV): записывается в начало зашифрованного файла и считывается при расшифровании.

Сборка:
  cd cipher
  make

Очистка скомпилированных файлов:
  make clean

Использование:
  ./cipher <режим> <входной_файл> <выходной_файл> <пароль>

Параметры:
  <режим>:
    enc — зашифровать файл.
    dec — расшифровать файл.
  <входной_файл>  — путь к исходному файлу.
  <выходной_файл> — путь к файлу для сохранения результата.
  <пароль>        — секретная строка (пароль), используемая для генерации ключа шифрования.

Примеры работы:

1. Зашифрование файла:
  ./cipher enc document.txt document.enc MySecretPassword123
  Вывод:
  Файл зашифрован: document.enc

2. Расшифрование файла:
  ./cipher dec document.enc document_restored.txt MySecretPassword123
  Вывод:
  Файл расшифрован: document_restored.txt

3. Проверка совпадения исходного и расшифрованного файлов:
  diff -s document.txt document_restored.txt
  Вывод: Files document.txt and document_restored.txt are identical
